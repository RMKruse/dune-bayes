# dune-bayes 0.1.0-paper Artifact Release Notes

Planned tag: `v0.1.0-paper`
Package version: `0.1.0`
Development version before release: `0.1.0.dev0`

This planned release is the citable research-software artifact for the first
dune-bayes paper. It freezes the source code, promoted canonical evidence, paper
artifact builder outputs, and bounded reproducibility audit reports used to
support the submitted manuscript.

## Evidence Bundle

The release evidence bundle is declared in
`experiments/publication/evidence-manifest.yaml` and includes:

- the disentanglement simulation for the law-of-total-variance decomposition;
- Normal, Gamma, Student-t, and Johnson's SU parameter-recovery artifacts for
  per-feature, per-parameter epistemic effect bands;
- the validation-only VI-versus-NUTS agreement artifact documenting
  mean-field VI band-width limitations;
- the canonical UCI benchmark/comparator panel under
  `experiments/uci_benchmark/results/canonical`.

The benchmark gate for comparator claims is
`experiments/uci_benchmark/results/canonical/benchmark-claims.yaml`. Optional
external comparators that are not part of the canonical claim are recorded there
with documented exclusions.

## Reproducibility Audit

Run the bounded audit before tagging:

```bash
uv sync --locked --extra dev --extra experiments
uv run python -m experiments.publication.audit \
  --root . \
  --output-dir experiments/publication/reproducibility-audit
```

The tag is releasable only when the Bounded Reproducibility Audit reports ready
in both:

- `experiments/publication/reproducibility-audit/audit-report.json`
- `experiments/publication/reproducibility-audit/audit-report.md`

The audit is bounded: it checks package gates, experiment smoke paths, evidence
manifest validation, benchmark publication gate validation, and paper artifact
assembly. Full canonical experiment reruns remain manual and are not implied by
the bounded audit.

## Citation State

`CITATION.cff` contains the repository citation and a pending preferred-citation
slot for the dune-bayes paper. Before creating `v0.1.0-paper`, replace the
pending paper fields with the author-approved preprint or submission citation,
including DOI when available.
